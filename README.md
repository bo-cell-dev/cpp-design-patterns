# C++ Design Patterns

Implementation of the 23 classic Gang of Four (GoF) design patterns in C++17. 

## Directory Structure
* `/Behavioral` — Behavioral patterns
* `/Creational` — Creational patterns
* `/Structural` — Structural patterns (each pattern is self-contained with its own `.h`, `.cpp`, and local `CMakeLists.txt`)
